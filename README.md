# Victoria Odalo, portfolio

Personal portfolio site built with HTML, CSS and JavaScript. Projects load from GitHub and articles from dev.to.

Live site: https://odalov.github.io

## Run locally

Open the folder in VS Code and start it with the Live Server extension.

## Structure

- `index.html`: page content
- `css/style.css`: styles
- `js/script.js`: GitHub and dev.to feeds
- `assets/`: photo and resume
